# Assets

| Put here                          | File name                                  |
| --------------------------------- | ------------------------------------------ |
| Profile photo                     | `images/profile.jpg` (or .png / .webp)     |
| Project screenshots               | `images/projects/<project-id>.jpg`         |
| 3D models (.glb)                  | `models/`                                  |
| Textures                          | `textures/`                                |
| Logos                             | `logos/`                                   |
| Resume PDF (optional)             | `docs/`                                    |

`<project-id>` is the `id` of the project in `src/data/portfolioData.ts`
(e.g. `personal-portfolio.jpg`). Files are detected automatically — no code changes needed.
